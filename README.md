
# nautica-docs

![CI](https://github.com/miky2000mahg-png/nautica-docs/actions/workflows/ci.yml/badge.svg)

Web de Náutica Bahía: tienda y alquiler de material náutico en Puerto de Mazarrón.

## Funcionalidades

- Portada con la presentación de la empresa.
- Página de contacto.
- Información sobre los servicios náuticos.

## Requisitos

- Un navegador web moderno.
- No se necesita servidor para ejecutar la versión estática.

## Cómo ejecutarlo en local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/miky2000mahg-png/nautica-docs.git
   cd nautica-docs
   ```

2. Abre `index.html` en el navegador.
